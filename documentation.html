Documentation

Video player setup

Add these stylesheet links to the <head> of your page.

Video player styles

Load the stylesheet that provides the custom player appearance.

<link rel="stylesheet" href="https://niki182.github.io/CineVault-video-player/src/video-styles.css">

Font Awesome icons

Load Font Awesome 7.2.0 or later to display all player control icons correctly. If you're using a version earlier than 7.0.0, update it. Older versions may not include the required icons.

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.2.0/css/all.min.css">

HTML code

Add these code to the <body> of your page.

<div class="video-container">
    <div class="video-stage">
        <video src="" id="video-custom-player"></video>
        <div class="video-overlay" id="video-overlay"></div>
        <img src="https://niki182.github.io/CineVault-video-player/assets/Spinner@1x-1.0s-200px-200px.gif" class="video-loader" id="video-loader" width="70" height="70">
        <button class="replay" id="replay-button">
            <i class="fa-solid fa-rotate-right"></i>
        </button>
    </div>

    <div class="controls">
        <div class="vid-controls-left">
            <button class="play-btn" id="play-button">

            </button>
            <div class="timestamp">
                <span id="current-time">0:08</span>

                <span id="end-time">0:08</span>

        </div>

</div>

The javascript tag

Add the JavaScript link before the closing </body> tag to enable the player controls.

<script src="https://niki182.github.io/CineVault-video-player/src/video-script.js"></script>
